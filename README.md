# Blog Post Viewer
A simple React application that fetches and displays blog posts using the JSONPlaceholder API. The app uses Axios for HTTP requests and implements an Error Boundary to gracefully handle rendering and API errors.

---

## Features
- Fetch blog data from a public API using Axios
- Display blog post titles and content
- Handle loading and error states cleanly
- Implement Error Boundaries for graceful error handling
- Responsive, clean UI with basic CSS

# Project Structure
```bash
src/
├── components/
│   ├── BlogPostList.js     // Renders the list of blog posts
│   └── ErrorBoundary.js    // Catches and displays fallback on render errors
├── App.js                  // Main component, fetches API data
├── App.css                 // Styling for the app
└── index.js                // Entry point
```
